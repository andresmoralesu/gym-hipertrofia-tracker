📋 Notas de Diseño

🏠 HOME - Página Principal

Propósito: Punto de entrada. Muestra variación actual, ejercicios del día y botón para comenzar.

  • Variación Card: Fondo oscuro con borde lima y accent. "Semana 3" resaltado en lima. Grupo muscular como badge lima.
  • Exercise List: Numerada con círculos lima. Cada item muestra nombre, series, reps y descanso.
  • CTA Principal: Botón lima prominente "Comenzar Entrenamiento" al final. Alto contraste para clickeability.
  • Next: Al hacer clic, navega a WORKOUT screen.

💪 WORKOUT - Pantalla de Entrenamiento

Propósito: Timer visual, logging de pesos, navegación entre ejercicios.

  • Timer: Monospace, 48px, fondo oscuro gradiente. Cuenta el descanso entre series.
  • Set Counter: Muestra "3 / 5" para feedback visual. Border naranja.
  • Weight Input: Campo para kg levantados. Se guarda en historialPesos DB.
  • Action Buttons: Verde "✓ Serie OK" para completar + Secundario "Saltar".
  • UX: Al completar todas las series, pasa al próximo ejercicio automáticamente.

📊 HISTORY - Historial

Propósito: Visualizar progresión histórica de ejercicios específicos.

  • Filter: Dropdown para seleccionar ejercicio (autopopulado desde datos históricos).
  • Stats Cards: Máximo y promedio de peso levantado (resaltado en lima, calculado en tiempo real).
  • Table: Fecha, series, peso. Sorteable por fecha. Peso resaltado en lima para rápida identificación.
  • Data Source: Lee de historialPesos store en IndexedDB.
  • Performance: Scrollable si hay muchos registros.

⚙️ SETTINGS - Configuración

Propósito: Google Drive sync, preferencias de app, peligro zone (borrar datos).

  • Google Sign-In: Botón blanco por defecto. Verde + checkmark cuando conectado.
  • Sync Status: Badge que dice "EN LÍNEA" o "DESCONECTADO" según conectividad.
  • Manual Sync: Botón secundario para forzar sincronización inmediata.
  • Dark Mode: Toggle (placeholder por ahora, implementar en Layer 6).
  • Danger Zone: "Borrar Historial" con fondo rojo suave para disuadir clicks accidentales.

🎨 Design System Compliance

  • Colors: Dark mode con lima (#d4fb50) como accent primario. Fondos oscuros (#0a0a0a, #1a1a1a), tinta (#14130f), texto claro (#f0f0f0).
  • Lima Accent (#d4fb50): Usado para botones, números, nav activo, highlights, badges. NO en grandes áreas de fondo con texto claro encima.
  • Typography: Jerarquía respetada (headings 24px, body 16px, small 14px, captions 12px).
  • Spacing: 8px grid. Padding consistente 20px móvil, gaps 12-24px entre elementos.
  • Components: Buttons, cards, inputs siguen Design System exactamente.
  • Accessibility: Touch targets ≥44px. Contraste 4.5:1 verificado. Responsive desde 390px.
  • Mobile-First: Layouts adaptativos. Notch y bezels considerados.

📱 Responsive Behavior

  • 390px (Mobile): Screens tal como se ven aquí. Full width, stacked layout.
  • 768px+ (Tablet): Tab navigation horizontal en top. Side-by-side layout posible.
  • 1200px+ (Desktop): Split view con sidebar navigation. Exercise list in grid.
  • No necesita rediseño: Layouts flexibles escalan bien a cualquier resolución.

🔄 Navigation Flow

Tab Navigation (implementar en Layer 2):

  • Home Tab: Muestra HOME screen (variación actual, ejercicios).
  • Workout Tab: WORKOUT screen (solo disponible si hay entrenamiento activo).
  • History Tab: HISTORY screen (tabla de progresión histórica).
  • Settings Tab: SETTINGS screen (config y sync).
